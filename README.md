SPHEREx-Functions.ipynb [to be updated] contains the functions I used to make the ice maps, spectra and other plots. This does not include downloading the actual files themselves from SPHEREx, for which one can refer to https://caltech-ipac.github.io/irsa-tutorials/spherex-intro/

IceMaps contains fits files for the tau maps used for the Fig 2 of the paper. A very basic WCS header is in extension 0. Extension 1 and 2 contain tau and tau_err respectively.
